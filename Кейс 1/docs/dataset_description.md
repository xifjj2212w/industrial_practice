# Описание журнала

Все пользователи, процессы, события, суммы и даты вымышлены. Данные представляют нормализованную учебную выгрузку: имена колонок не являются контрактом ELMA365 API.

Даты стартов: 12 января — 30 июня 2026 года. **Срез наблюдения: 1 июля 2026 года, 00:00, UTC+03:00.** События после среза отсутствуют. Рабочий календарь учебной организации: понедельник–пятница, 09:00–18:00, без отдельного учёта государственных праздников и обеда. Учитывайте календарную и рабочую длительность отдельно. Количество процессов и события можно посчитать самостоятельно.

| Поле | Значение |
|---|---|
| ProcessInstanceId | UUID одной заявки; по нему группируются события |
| EventId | Уникальный идентификатор записи выгрузки |
| EventIndex | Последовательный числовой индекс внутри процесса; разрешает порядок при одинаковой секунде |
| EventType | Тип события, см. ниже |
| ActivityId | Стабильный путь элемента вида /items/UUID; один этап повторно использует тот же ID |
| ActivityName | Понятное название этапа |
| TaskId | UUID конкретного задания; повторное выполнение этапа создаёт новое задание |
| Timestamp | ISO 8601 с часовым поясом; время события |
| UserId | Фактический пользователь при закрытии задания; инициатор при старте |
| Role | Роль фактического пользователя; не роль, ожидаемая по этапу |
| Status | Состояние после события; область зависит от EventType |
| Result | Результат закрытия/завершения |
| RequestType | standard — обычная, urgent — срочная, contract — договорная заявка |
| Amount | Сумма заявки в условных рублях, десятичная точка |
| TemplateVersion | Версия схемы процесса; в этой выгрузке одна версия |

| EventType | Значение | Status | Result |
|---|---|---|---|
| process_started | Создан и запущен экземпляр | exec | пусто |
| automatic_completed | Выполнена регистрация | completed | пусто |
| task_created | Создано человеческое задание | in_progress | пусто |
| task_completed | Человеческое задание закрыто | closed | accept / return / reject |
| process_completed | Завершён процесс | done | fulfilled / rejected |

У `task_created` UserId и Role пустые: фактический исполнитель ещё не известен. У автоматического действия UserId пустой, Role=system. У завершения процесса исполнитель не указан. Пустое поле не считается автоматически ошибкой. Status задач и процесса — разные множества; completed для автоматического действия — учебное значение.

Длительность задания: Timestamp закрытия минус Timestamp создания с тем же TaskId. Повторный ActivityId не обязательно означает дубликат: этап мог выполняться после возврата. Если закрытия нет, известен только нижний предел длительности до среза. Если задание ещё не создано, длительность будущего этапа неизвестна.

CSV использует запятую и UTF-8 с BOM. В Excel импортируйте через «Данные → Из текста/CSV», выберите запятую, UTF-8 и сохраняйте UUID как текст. Если Excel не разбирает ISO-дату, сначала преобразуйте колонку в Power Query с учётом часового пояса; не сравнивайте даты как обычные числа. Для анализа маршрутов сортируйте внутри процесса по числовому EventIndex. Файл в целом отсортирован по времени, поэтому строки одной заявки не обязательно идут подряд.
