# Формат сдачи

## anomalies.csv

Запятая как разделитель, UTF-8; точные заголовки:

```csv
ProcessInstanceId,AnomalyType,Explanation
```

Используйте реальные ProcessInstanceId из полученного журнала. AnomalyType — выбранное вами короткое название типа; можно писать по-русски. Explanation — конкретный факт и аргумент: этап, порядок, длительность, сравнение с обычными заявками, роль и т. п. Для нескольких отклонений одного процесса допускаются несколько строк. Не дублируйте одинаковые строки. Если объяснение содержит запятую или перенос строки, заключите его в двойные кавычки по правилам CSV.

## Краткий отчёт (2–4 страницы или эквивалент)

1. Инструменты и воспроизводимые шаги анализа.
2. Что вы считаете обычным поведением и на каких данных основан вывод.
3. Критерии поиска, выбранные сравнения и причины выбора.
4. Полученные результаты: количество кандидатов, виды отклонений, несколько наиболее показательных примеров.
5. Ложные срабатывания, ограничения, незавершённые процессы и случаи для ручной проверки.
6. Использование AI: для каких задач, как проверяли результат; либо «не использовался».

При работе в Excel приложите файл или точное описание фильтров, сводных таблиц и формул. При работе с кодом приложите код/ноутбук и инструкции запуска. Разрешена сдача без программирования.
